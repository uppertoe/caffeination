How this was calculated

{{ v.premise }}, each cell would hold its row total multiplied by its column total, divided by all {{ t.n }} drinks. That expected count, E, is shown under each observed count, O. Each cell contributes (O − E)² ÷ E, and the contributions add up to χ²:

χ² = {% for line in v.cells %}{% for cell in line %}{{ '%.2f' % cell.contribution }}{% if not loop.last %} + {% endif %}{% endfor %}{% if not loop.last %} + {% endif %}{% endfor %} = {{ '%.2f' % t.chi2 }}

The textbook test compares χ² with a χ² distribution on {{ t.df }} {{ "degree" if t.df == 1 else "degrees" }} of freedom, which gives {{ p_eq(t.p_textbook) }}.{% if t.sparse_cells %} Because {{ t.sparse_cells }} of the {{ v.rows | length * v.cols | length }} cells are expected to hold fewer than 5 drinks, that figure is unreliable.{% endif %}

The permutation test shuffles the {{ v.col_name | lower }} column {{ t.null | length }} times, keeping every total fixed. {{ t.as_extreme }} of the shuffled tables had a χ² at least as large as the department’s, which gives the permutation p-value of {{ pval(t.p_permutation) }}.
