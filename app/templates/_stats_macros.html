How this was calculated

{{ independent }} If {{ v.row_name | lower }} and {{ v.col_name | lower }} were chosen independently, each cell would be expected to hold its row total multiplied by its column total, divided by all {{ t.n }} drinks. That expected count is shown under each observed count.

Each cell contributes (O − E)² ÷ E, and the contributions add up to the χ² statistic:

χ² = {% for line in v.cells %}{% for cell in line %}{{ '%.2f' % cell.contribution }}{% if not loop.last %} + {% endif %}{% endfor %}{% if not loop.last %} + {% endif %}{% endfor %} = {{ '%.2f' % t.chi2 }}

The textbook p-value compares χ² with a χ² distribution on {{ t.df }} {{ "degree" if t.df == 1 else "degrees" }} of freedom, which gives p = {{ pval(t.p_textbook) }}.{% if t.sparse_cells %} {{ t.sparse_cells }} of the {{ v.rows | length * v.cols | length }} cells are expected to hold fewer than 5 drinks, which makes the textbook p-value unreliable.{% endif %}

A permutation test makes no such assumption. It shuffles the {{ v.col_name | lower }} column {{ t.null | length }} times, keeping every row and column total fixed, and recalculates χ² for each shuffled table. {{ t.as_extreme }} of the {{ t.null | length }} shuffled tables had a χ² at least as large as the real one, so p = ({{ t.as_extreme }} + 1) ÷ {{ t.null | length + 1 }} = {{ pval(t.p_permutation) }}.
